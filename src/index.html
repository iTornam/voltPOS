Step 2 — Set Your Owner PIN

YOUR OWNER PIN RECOVERY CODE
If you forget the Owner PIN, this code is the only way back in. Write it down or take a photo and keep it private. A copy was also saved as RECOVERY.txt in your data folder (File → Open Data Folder) — move it somewhere safe, then delete it.
